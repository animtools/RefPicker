# screenshots

README / QUICKSTART / USER_GUIDE から `./screenshots/<name>.jpg` の形で参照する画像を置きます。

## 撮影リスト（予定）

「参照をピンポイントで絞り込む」体験を主役に、次のカットを想定しています。

- `filter_before_after.jpg` — 絞り込み前後のグリッド（キーワード入力で一気に絞られる様子）
- `root_register.jpg` — 設定からルートフォルダを登録する
- `filter_history.jpg` — 絞り込み履歴の呼び出し
- `crop_tools.jpg` — 多角形／フリーハンド切り抜き
- `export_clipboard.jpg` — 切り抜きをクリップボード／フォルダへ書き出し
- `comparison_sheet.jpg` — 対比表 PNG の書き出し

> 撮影後、各ドキュメントの該当箇所に画像を挿入する。
