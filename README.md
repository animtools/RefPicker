# RefPicker（参照ピッカー）

> 作画の"今ほしい参照"を一瞬で絞り込む
> アニメ制作の設定資料フォルダをそのまま索引化し、必要な参照画像をピンポイントで探し出す Windows デスクトップアプリです。

---

## こんな方へ

- **作画** — 大量の設定・資料フォルダから「今描くカットに要る参照」を素早く出したい
- **制作進行** — 資料一式を索引化し、アニメーターへ渡す・同期する準備を軽くしたい
- **設定制作** — キャラの身長対比表など、配布用の資料を手早く作りたい

## RefPicker が解決すること

設定資料は膨大で、フォルダを開いては閉じ、名前で当たりを付けて探す時間が積み上がります。RefPicker は、登録したフォルダを丸ごと索引化し、**キーワードの絞り込みと履歴**で「今ほしい参照」に一直線でたどり着けるようにします。見つけた画像はそのまま**切り抜いてクリップボードや作業フォルダへ**渡せます。

## 主な機能

| 機能 | 説明 |
|------|------|
| **フォルダ索引化** | 資料フォルダを登録すると配下を再帰スキャンして一覧化。ファイル追加も監視して自動反映 |
| **絞り込み（OR フィルタ）＋履歴** | キーワードで一覧を即絞り込み。よく使う条件は履歴から復元 |
| **探索から除外** | 見たくないフォルダ／ファイルをツリーで除外（元ファイルは消しません） |
| **切り抜き** | 多角形・フリーハンド・矩形で必要部分を切り出し。平滑化・ルーペ付き |
| **クリップボード／フォルダ書き出し** | 切り抜き PNG を他アプリへ貼り付け、または任意フォルダへ書き出し |
| **メジャー正規化** | 基準（メジャー）に合わせてクリップの実寸を揃える |
| **対比表（PNG）** | キャラの背比べなど、共通ベースライン・目盛り・名前ラベル入りの 1 枚 PNG を書き出し |
| **プロジェクトの共有** | 制作進行が資料一式を配り、アニメーターが受け取る。追加・更新は差分だけが流れる。**受け取り側にライセンスは不要** |

> データはすべて**端末内のローカル**に保存されます（クラウドへ自動送信しません）。元ファイルは非破壊です。

## ダウンロード

> **※ 現在はテスト配布中です。**一般公開はしていません。ZIP は直接お渡ししています。
> 公開の準備が整い次第、配布先をここに記載します。

お渡しした **RefPicker-vX.Y.Z-win64.zip** を解凍して `RefPicker.exe` を起動してください。

- 動作環境: Windows 10 / 11（64bit）。Microsoft Edge WebView2 ランタイム（Windows 11 は標準搭載）。
- インストール不要のポータブル版です。
- 未署名のため、初回起動時に SmartScreen の警告が出ることがあります（[QUICKSTART.md](./QUICKSTART.md) 参照）。
- **更新版を受け取ったら、古い解凍先を消してから解凍し直してください**（[QUICKSTART.md](./QUICKSTART.md) 参照）。
