# RefPicker（参照ピッカー）

> 作画の"今ほしい参照"を一瞬で絞り込む
> アニメ制作の設定資料フォルダをそのまま索引化し、必要な参照画像をピンポイントで探し出す Windows デスクトップアプリです。

---

## こんな方へ

- **作画** — 大量の設定・資料フォルダから「今描くカットに要る参照」を素早く出したい
- **制作進行** — 資料一式を索引化し、アニメーターへ渡す・同期する準備を軽くしたい
- **設定制作** — キャラの対比表など、配布用の資料を手早く作りたい

## RefPicker が解決すること

設定や資料は膨大です。フォルダを開いては閉じ、名前で当たりを付けて探す時間が積み上がります。

RefPicker は、登録したフォルダを**丸ごと索引化**します。あとは**キーワードを打つだけ**で、今ほしい参照が出ます。よく使う条件は履歴から呼び戻せます。

欲しい範囲は**切り抜き範囲を指定して**並べて見ることができます。必要な切り抜き部分だけを、クリップボードや外部アプリへ渡せます。

## 主な機能

| 機能 | 説明 |
|------|------|
| **フォルダ索引化** | 資料フォルダを登録すると配下を再帰スキャンして一覧化。ファイルの追加も自動で検知して反映 |
| **絞り込み＋履歴** | キーワードで一覧を即絞り込み。よく使う条件は履歴から復元 |
| **探索から除外** | 見たくないフォルダ／ファイルをツリーで除外（元ファイルは消しません） |
| **切り抜き** | 多角形・矩形で必要な部分を切り出し。ルーペ付き |
| **クリップボード／フォルダ書き出し** | 切り抜き PNG を他アプリへ貼り付け、または任意フォルダへ書き出し |
| **メジャー正規化** | 基準（メジャー）に合わせてクリップの実寸を揃える |
| **対比表（PNG）** | キャラ対比など、共通ベースライン・目盛り・名前ラベル入りの 1 枚 PNG を書き出し |
| **プロジェクトの共有** | 制作進行が資料一式を配り（共有元）、アニメーターが受け取る（共有先）。資料の追加・更新は差分だけ更新。**共有先にライセンスは不要** |

> **アプリが外部へ送信することはありません。** 索引・切り抜き・タグは端末内に保存されます。
> **共有は、指定したフォルダに書き出すだけ**です（社内 NAS・共有ドライブ・クラウドのいずれでも構いません）。
> 元ファイルは非破壊です。

## ダウンロード

**[→ 最新バージョンをダウンロード](https://github.com/animtools/RefPicker/releases)**（無料・アカウント登録なし）

> **注意：テスト版として公開しています。** 現場での検証中で、仕様が変わることがあります。
> 使ってみた感想・詰まった点をいただけると助かります（[SUPPORT.md](./SUPPORT.md)）。

`RefPicker-vX.Y.Z-win64.zip` を解凍して `RefPicker.exe` を起動してください。

- 動作環境: Windows 10 / 11（64bit）。Microsoft Edge WebView2 ランタイム（Windows 11 は標準搭載）。
- インストール不要です（ZIP を解凍して `RefPicker.exe` を起動）。
- 未署名のため、初回起動時に SmartScreen の警告が出ることがあります（[QUICKSTART.md](./QUICKSTART.md) 参照）。
- **新しいバージョンに更新するときは、`RefPicker.exe` だけを上書きしてください。**⚠ **解凍先のフォルダごと消さないでください** — データは exe と同じフォルダの `RefPickerData` に入っています（[QUICKSTART.md](./QUICKSTART.md) 参照）。

### 補足事項

- **配られた資料（共有プロジェクト）を使う側（受け取る側）に、ライセンスは要りません。** 受け取る数にも上限はありません。
  複数のスタジオ・複数の作品から配られても、ライセンス不要で全ての共有プロジェクトを取り込んで開くことができます。（無料枠の「1件」に数えるのは
  **自分で作る**プロジェクトだけで、**受け取ったものは数に入りません**）。
- **絞り込みや文字列でのタグ付け（自由タグ）はライセンス認証不要で使えます。**
  認証が要るのは**分類タグ**——顔の向き・表情などを**決まった値から選ぶ**タグ——を
  **付ける／外す**ときだけです（分類タグが付いた資料を受け取れば、その分類タグでの絞り込み利用は可能）。
- **作ったデータはライセンス失効後も消えません。** 受け取った資料も分類タグもボードもそのまま残り、
  それらでの絞り込みも使い続けられます。
