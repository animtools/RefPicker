Features

現場の動線に合わせた 6 つの機能

「探す → 切り抜く → 貼る → 揃える → 配る」。設定資料まわりの一連の流れを、そのままアプリにしました。

フォルダ登録だけの高速索引

資料フォルダを「ルート」として登録するだけで再帰スキャンし SQLite に索引化。ファイル監視で追加・変更にも自動追従します。フォルダ構成は一切変えません。

タグ×パスの瞬間フィルタ

「主人公, 頭部, 正面」のように複数語で絞り込み。相対パスと切り抜きタグに部分一致し、条件は履歴からワンクリックで復元。部位・アングル・向きのプリセット語彙も同梱。

多角形・フリーハンド切り抜き

設定画の必要な部分だけを多角形・フリーハンド・矩形で切り抜き。フリーハンドは平滑化を調整可能。切り抜きにはタグを付けて、それ自体が検索対象になります。

コピーして、そのまま貼る

切り抜きは PNG としてクリップボードへ（Windows のファイル貼り付け形式）。CLIP STUDIO PAINT や Photoshop など、ファイル貼り付け対応アプリへ直接持ち込めます。ドラッグ書き出し・フォルダ書き出しも。

メジャーで頭身・対比を正規化

キャラごとに「全身」「頭部」などのメジャー（基準線）を割り当てると、基準キャラとの対比でサイズが自動で揃います。頭身チェックやサイズ感の確認が目分量から卒業できます。

対比表 PNG を数クリックで

ピンした切り抜きを共通ベースラインに整列し、目盛り・キャラ名・タイトル・©表記まで焼き込んだ配布用 PNG を生成。設定が改訂されても、開き直せば最新の見た目で再構成されます。

Trust

現場の資料を預かるツールとして、
守っていること。

設定資料は作品の機密そのものです。だから、疑いようのない設計にしました。

データはすべてローカル

索引 DB（SQLite）・サムネイル・切り抜きは、あなたの PC のアプリデータフォルダにのみ保存。クラウドへの自動アップロードは一切ありません。共有は自分で選んだ共有フォルダか ZIP だけです。

元ファイルには手を触れない

ルート登録は索引を作るだけ。ファイルの移動・リネーム・削除は行いません。ルートをアプリから外しても、ディスク上のフォルダはそのまま残ります。

ネイティブの速さ

Rust + SQLite によるネイティブ実装と仮想スクロールで、数千枚規模の索引も軽快に。オフラインでも全機能が動作します（同期チャネルの受け渡しを除く）。

FAQ

よくある質問

資料が外部に送信されることはありませんか？
ありません。索引・サムネイル・切り抜きはすべてローカル PC 内に保存されます。チーム共有を行う場合も、あなたが指定した共有フォルダまたは ZIP ファイルを経由するだけで、アプリが独自にネットワーク通信を行うことはありません。NDA 下の資料でも安心して扱えます。
既存のフォルダ構成を変える必要はありますか？
不要です。今使っている資料フォルダをそのまま「ルート」として登録するだけです。ファイルの移動・リネームは行わず、削除もしません。ルート登録を外しても索引から消えるだけで、実ファイルには影響しません。
切り抜きは CLIP STUDIO PAINT や Photoshop に貼れますか？
はい。切り抜きは PNG ファイルとしてクリップボードにコピーされ（Windows のファイル貼り付け形式 CF_HDROP）、ファイル貼り付けに対応したアプリへそのまま Ctrl+V できます。フォルダへの書き出しや、エクスプローラー・他アプリへのドラッグ書き出しにも対応しています。
複数のスタジオの案件を同時に抱えていますが、混ざりませんか？
混ざりません。案件（プロジェクト）ごとに索引 DB・切り抜き・同期設定が完全に分離されており、画面上部のプロジェクト切替で行き来します。「発注元 / 案件名」のラベルで見分けられ、開いていない案件の資料更新もバッジで通知されます。ZIP 取り込み時も projectId が照合され、別案件への誤適用は拒否されます。
制作進行が配った資料を、受け取り側が壊してしまうことは？
できない設計です。公式資料の切り抜き形状や同期元タグは受け取り側から変更・削除できず、可能なのは「タグの追加」と「個人ルートの追加」だけです。更新の適用は必ずプレビューを経由し、手元の追加タグと衝突する場合は競合として明示されます。
対比表の目盛りは実寸（cm）で出せますか？
はい。メジャーに数値を設定していれば実寸目盛り、なければ基準キャラ＝100 とする相対目盛りで描画されます（自動判定／固定の切り替え可）。目盛り範囲・刻み・単位も調整でき、タイトル・サブタイトル・©フッターまで含めて 1 枚の PNG に焼き込みます。
導入にサーバーや管理者は必要ですか？
不要です。各自の PC にアプリを置くだけで動作し、チーム同期も既存の共有フォルダ・NAS・ZIP 手渡しをそのまま使います。専用サーバーの構築やアカウント登録は一切ありません。
